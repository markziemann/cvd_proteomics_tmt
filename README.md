# cvd_proteomics_tmt
Analysis of TMT multiplexed proteomics

Mathanki Mehra analysed the RAW files with fragpipe to generate the abundance measurements
separately for plex A/B.

She also wrote an R script (Analysis2.Rmd) to read in the data and conduct analysis with Limma.

Mark made a copy of the script (Called analysis4_mz.Rmd) and made some modifications to do
additional exploratory analysis.
